# Workflow C — Fournisseurs disponibles

**But :** vérifier, pour chaque fournisseur effectivement configuré, que les opérations IA principales restent exécutables.

## Étapes

1. Associer au projet le fournisseur à tester.
2. À partir de `manuscrit-passage.md`, effectuer une réécriture, une autocomplétion et une génération de chapitre.
3. Générer ensuite une métadonnée, par exemple l'analyse narrative.
4. Noter le fournisseur, le modèle, les erreurs éventuelles, la langue produite et le coût indiqué dans l'application.

## Verdict

Une opération réussie produit une réponse exploitable sans erreur de configuration. Ne pas exiger un nombre fixe de propositions, un libellé de style particulier, une qualité identique ou un coût identique entre OpenAI, Anthropic et Google : ces éléments dépendent du modèle choisi.
