## 1. SITUATION INITIALE
- Statu quo au début du récit
- Monde ordinaire du protagoniste
- Éléments de stabilité
- Éléments d'instabilité latente (foreshadowing)

## 2. ÉLÉMENT DÉCLENCHEUR
- Événement qui perturbe l'équilibre
- Moment précis (chapitre, page)
- Réaction du protagoniste
- Refus de l'appel (si présent)

## 3. ENJEUX
- Enjeu principal : qu'est-ce qui est en jeu ?
- Enjeux secondaires
- Conséquences de l'échec (stakes)
- Enjeux internes (psychologiques) vs externes (concrets)

## 4. QUESTIONS DRAMATIQUES
- Question centrale : "Est-ce que [protagoniste] va [objectif] ?"
- Questions secondaires ouvertes
- Mystères posés explicitement
- Mystères implicites

## 5. CONFLITS
Pour chaque conflit identifié :
- Type (homme vs homme / société / lui-même / nature / technologie / destin)
- Personnages impliqués
- Enjeu du conflit
- État actuel (latent, ouvert, résolu, en escalade)

## 6. FILS NARRATIFS
- Intrigue A (principale) : résumé en 2 lignes, % d'avancement estimé
- Intrigue B : résumé, avancement
- Intrigue C : résumé, avancement
- Intersections entre les fils

## 7. STRUCTURE DÉTECTÉE
- Modèle structurel apparent (3 actes, 5 actes, voyage du héros, autre)
- Position actuelle dans la structure
- Points de basculement (plot points) identifiés
- Points de basculement attendus
