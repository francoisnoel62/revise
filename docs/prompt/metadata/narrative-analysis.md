## 1. NARRATEUR
- Type : 1ère personne / 3ème limitée / 3ème omnisciente / autre
- Si 1ère personne : qui est le narrateur ? fiable ou suspect ?
- Si 3ème personne : sur qui est focalisé le récit ?
- Distance narrative (proche/moyenne/distante)
- Intrusions du narrateur (commentaires, jugements, adresses au lecteur)

## 2. FOCALISATION
- Type dominant (interne/externe/zéro)
- Accès aux pensées : quels personnages ? quelle profondeur ?
- Variations de focalisation entre chapitres/scènes
- Informations cachées au lecteur volontairement

## 3. TEMPORALITÉ
- Temps verbal dominant
- Cohérence temporelle (oui/non, signaler les écarts)
- Durée diégétique couverte (estimation)
- Rapport temps narré / temps de narration
- Analepses (flashbacks) : fréquence, déclencheurs, marqueurs
- Prolepses (anticipations) : présence, fonction

## 4. GESTION DU TEMPS NARRATIF
- Scènes (temps réel) vs Sommaires (résumés)
- Ellipses : comment sont-elles signalées ?
- Pauses descriptives : fréquence, longueur
- Accélérations et ralentissements : où et pourquoi ?

## 5. STRUCTURE DES CHAPITRES
- Longueur moyenne (en mots, estimation)
- Pattern d'ouverture (in medias res, description, dialogue, introspection)
- Pattern de clôture (cliffhanger, résolution, suspension, révélation)
- Unité des chapitres (temps, lieu, action, POV)
