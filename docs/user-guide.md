# Revise - Guide Utilisateur

## Introduction

Revise est un outil d'aide à l'écriture minimaliste qui vous permet de réécrire instantanément vos textes grâce à l'IA.

## Fonctionnalités

### Import de Documents

1. Cliquez sur "Importer"
2. Sélectionnez un fichier .docx
3. Le document est divisé en chapitres (selon les titres H1)
4. Si aucun titre H1 n'est détecté, un seul chapitre est créé

### Navigation entre Chapitres

1. Cliquez sur l'icône 📄 en haut à gauche
2. Votre liste de chapitres s'affiche
3. Cliquez sur un chapitre pour le charger
4. Si vous avez des modifications non enregistrées, une confirmation apparaît

### Gestion des Chapitres

**Ajouter un chapitre**:
- Cliquez sur "Nouveau chapitre" dans le panneau de navigation

**Renommer un chapitre**:
- Le titre du chapitre apparaît en haut de la page
- Cliquez pour modifier (future feature)

**Réorganiser les chapitres**:
- Glissez-déposez les chapitres dans le panneau de navigation

**Supprimer un chapitre**:
- Cliquez sur l'icône poubelle à côté du chapitre
- Attention : vous ne pouvez pas supprimer le dernier chapitre

### Formatage du Texte

Utilisez la barre d'outils au-dessus de l'éditeur :
- **Gras** : Ctrl+B
- *Italique* : Ctrl+I
- Souligné : Ctrl+U
- Surligné : Ctrl+Shift+H

### Réécriture par IA

1. Sélectionnez le texte à réécrire
2. Cliquez sur "Réécrire" au-dessus de la sélection
3. 5 propositions apparaissent à droite
4. Cliquez sur "Insérer" pour la proposition choisie
5. Le texte original est remplacé
6. Utilisez Ctrl+Z pour annuler si besoin

### Export de Documents

1. Cliquez sur "Exporter"
2. Tous les chapitres sont exportés dans un seul fichier .docx
3. Les chapitres sont séparés par des sauts de page
4. Le formatage (gras, italique, etc.) est préservé

## Limitations Connues

- **Page Breaks**: Les sauts de page ne sont pas détectés à l'import
- **Formatage Complexe**: Tableaux, images, et styles complexes ne sont pas préservés
- **Undo/Redo**: L'historique est partagé entre tous les chapitres
- **Auto-save**: Pas de sauvegarde automatique (utilisez Export régulièrement)

## Résolution de Problèmes

**"Unsupported file format"**:
- Vérifiez que le fichier est bien au format .docx (pas .doc)

**L'import ne fonctionne pas**:
- Vérifiez que le fichier n'est pas corrompu
- Essayez de réexporter depuis Word

**Le formatage est perdu**:
- Seuls gras, italique, souligné et surligné sont supportés
- Le formatage complexe ne peut pas être préservé

**Les propositions IA ne s'affichent pas**:
- Vérifiez que votre sélection contient du texte
- Vérifiez votre connexion internet
- La génération prend 1-3 secondes

## Raccourcis Clavier

- **Ctrl+B**: Gras
- **Ctrl+I**: Italique
- **Ctrl+U**: Souligné
- **Ctrl+Shift+H**: Surligné
- **Ctrl+Z**: Annuler
- **Ctrl+Shift+Z**: Refaire
- **Esc**: Fermer les panneaux
